# todo-app


## 📌 概要

業務時間中に行った作業やタスク、考えたことを時系列で記録し、あとから検索・可視化・管理できるアプリ。将来的には以下の機能も備える：

* Redmineのようなタスク管理機能
* GitHubの草（contribution graph）のような可視化
* APIベースで他のツールとも連携可能に

## 🔧 使用技術（予定）

* フロントエンド: Next.js + TypeScript + Tailwind CSS
* バックエンド: Next.js API Routes + Prisma ORM
* DB: SQLite または PostgreSQL
* グラフ: Recharts または Chart.js
* 認証: NextAuth.js（将来的に）

## 🐳 開発環境

* Docker + Docker Compose
* TypeScriptのコンパイルはDockerコンテナ内で実行
* ホットリロード対応

## 🎯 ユースケース

* 自分の毎日の作業ログを簡単に記録したい
* 日報としてまとめて見返したい
* プロジェクト別やタグ別に作業を振り返りたい
* タスク管理や進捗の見える化をしたい

## 🧱 機能一覧

### ✅ MVP（最小構成）

* [ ] 作業ログの作成（テキスト、開始/終了時刻、プロジェクト、タグ）
* [ ] ログ一覧表示（日付順）
* [ ] ログの編集・削除
* [ ] ログの検索（キーワード、日付、タグ）
* [ ] ローカルまたはDBに保存（Prisma）

### 📊 拡張機能

* [ ] GitHubの草のような作業履歴カレンダー
* [ ] プロジェクト・タグ管理（CRUD）
* [ ] 日報生成（その日のログをMarkdownで出力）
* [ ] CSV/JSONエクスポート
* [ ] 月次レポート作成機能

### 🗂 タスク管理（Redmine風）

* [ ] タスクの作成・進捗管理（ToDo/In Progress/Done）
* [ ] タスクにログを紐付ける
* [ ] タスクの優先度・期限設定
* [ ] タスクの並び替え・フィルタ

### 🔐 その他将来的な機能

* [ ] ユーザー認証・セッション管理（NextAuth）
* [ ] モバイル対応
* [ ] 外部連携（GitHub, Slackなど）
